Grocery Delivery System 🛒
Python-based simulation of a grocery delivery platform with role-based access, dynamic deliveries, and multi-user orders.

Features ⚡
Roles:
  Admin → Manage inventory, view customers, process orders, add admins
  User → Register, search products, place & track orders
Delivery:
  Real-world distances using geopy
  Shortest-path routing with Dijkstra
Orders:
  Multi-user simulation with threading
  Orders queued and processed dynamically
Data Structures:
  Linked lists → customers
  Queue → orders
  Heap → shortest path
Tech Stack 🛠️
  Python | geopy | threading | collections | heapq
Register/Login
  Admin: manage inventory & users
  User: search, order, track
Future Ideas 🌟
  Real-time maps for delivery
  AI-based route optimization
  Web front-end integration
